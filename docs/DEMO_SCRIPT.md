# Milestone 2 video: shot list (target ≈ 2 min 15 s, within the 90–150 s limit)

Record the screen at 1080p with the live app. Before recording:
1. Open the app in a fresh tab so the boot animation plays (or open it in a private window).
2. Make sure animations are **on** (✦ button in the header).
3. Go to **Impact → Remove demo data**, then **Load demo data**, so the dashboard and console have content.

Each member can narrate one or two segments, matching the work they actually did.

| Time | Screen | Action | Narration (suggested) |
|---|---|---|---|
| 0:00–0:12 | Boot screen → Home | Let the "Reboot Earth" boot animation play; globe powers on | "We're Team Reboot-Earth. This is TechCycle, our e-waste repair and reuse platform." |
| 0:12–0:25 | Home → stats | Scroll to the statistics and the four problem cards | "In 2022 the world generated 62 million tonnes of e-waste, and only 22.3% was formally recycled. Many devices are thrown away while still repairable." |
| 0:25–0:55 | Check device | Smartphone · Mid-range · 2 years · cracked screen → **Analyse**. Then budget earphones · 1.5 yrs · battery | "Our engine scores repairability from 0 to 100 using repair cost, device age and fix success rate, and shows why. A cracked screen scores 66, so repair it. Budget earbuds with a dead battery score 26, so recycle responsibly." |
| 0:55–1:10 | Find services | Click **Recyclers**, toggle **Pickup available**, click **Show on map** | "The locator shows nearby repair shops, refurbishers, collection points and recyclers, sorted by distance. These are sample partners for now." |
| 1:10–1:30 | Book & track | Book a repair: show one validation error (wrong phone), fix it, submit → request ID + animation | "Booking validates every field and gives a trackable ID. For recycling, users must confirm a data-wipe checklist first." |
| 1:30–1:45 | Partner console → Track | Advance the new request to *Completed* (enter the final cost), then open its tracking page | "Partners update each stage, and the customer's timeline updates instantly." |
| 1:45–1:55 | Impact | Show KPIs and charts | "Impact counts only completed work: kilograms diverted, CO₂e avoided and money saved." |
| 1:55–2:05 | Parts market | Search "SSD", reserve an item | "A marketplace for tested parts and refurbished devices encourages reuse." |
| 2:05–2:15 | Design docs | Scroll the architecture diagram, click **Run test suite** (20/20 passing) | "Our design docs cover the architecture, data flow, data model and Business Model Canvas, and the automated tests run live. Next, in Milestone 3, we add a backend and real partner data." |

Tips: keep the cursor movements slow, zoom the browser to about 110% for readability, and add captions for the key numbers.
